# Hamza Raheem Portfolio

A multi-page static portfolio for Hamza Raheem, designed for the CS313 Web Engineering lab requirements.

## Structure

- `index.html` — portfolio landing page
- `skills.html` — technical expertise
- `gallery.html` — local visual gallery
- `hobbies.html` — interests beyond code
- `contact.html` — contact links
- `css/style.css` — shared external stylesheet
- `images/` — local SVG gallery assets

## Run locally

Open `index.html` in a browser. No JavaScript or framework is required.
